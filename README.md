# 創業貸款準備助手（信扶專案）網站

網址：https://xinfu-assistant.vercel.app ，由 Vercel 從這個 repo 自動部署（推上 `main` 約 1 分鐘後更新）。

| 網址 | 內容 |
|---|---|
| `/` | 引導員版 |
| `/review` | 審查人員版（第一次使用要輸入審查通行碼） |
| `/videos/guide.mp4`、`/videos/reviewer.mp4` | 教學影片 |

- 填寫的資料只存在使用者自己的瀏覽器；網站不收資料、沒有分析追蹤，頁面也不能連到其他網站。
- 不讓搜尋引擎收錄（`X-Robots-Tag: noindex`），也不能被嵌進其他網頁。
- 審查通行碼只用來開通瀏覽器，不是加密：會看網頁原始碼的人仍讀得到審查人員版的內容，所以 AI 審核注意事項不要寫機密或個資。

## 更新內容

審查人員在「維護內容」改了作業說明或 AI 審核注意事項之後：

1. 在「維護內容」按「匯出引導員版」「匯出審查人員版」，會下載兩個 HTML 檔。
2. 把兩個檔案的檔名都改成 `index.html`。
3. 到這個 repo：
   - 引導員版：在 repo 首頁按「Add file」→「Upload files」，拖進引導員版的 `index.html`，按「Commit changes」。
   - 審查人員版：先點進 `review` 資料夾，再用同樣方式上傳審查人員版的 `index.html`。
4. 約 1 分鐘後網站自動更新。

上傳需要這個 repo 的寫入權限，請 repo 擁有者在 Settings →「Collaborators」加入負責的同仁。

## 從檔案版換到網頁版

網址不同，瀏覽器裡的進度不會自動帶過來：在原本的檔案版按「備份」，再到網站按「還原」。

## 教學影片

重新錄製後，取代 `videos/guide.mp4`、`videos/reviewer.mp4`（單一檔案請小於 25 MB，才能用網頁上傳）。
